Smart Medicine Dispenser

Grade 6 Robotics Project

Course overview

Build a smart medicine dispenser with ESP32 and robotics skills.

Students learn how sensors, motors, timekeeping, logic, and communication work together in one real project. The class follows a 26–28 week plan with foundations, coding, testing, and a final demo.

26–28 weeks
6 core lectures
1 final system

Project goal

A safe medicine dispenser checks the time, confirms a dose is needed, rotates the right compartment, checks whether the tablet was released, and warns a caregiver if something is wrong.

Input → Process → Output
ESP32
RTC
IR sensor
Servo / stepper

Course learning goals

  • Understand robotics parts and how they work together.
  • Read time with an RTC and compare it to a medicine schedule.
  • Use sensors to detect whether a tablet was dispensed.
  • Control motors and rotate a medicine carousel safely.
  • Connect to Wi-Fi and share patient or caregiver alerts.

Bloom focus

Understand: explain each part and why it matters.

Apply: build and test each circuit and code block.

Create: combine modules into one working dispenser.

Project code

Starter firmware for the medicine dispenser

The code below is organized by lecture topic so students can see the logic in simple sections.

How to read this code: each block is a small step. The code checks time, decides if medicine is due, moves the carousel, and checks if the tablet actually came out.

Firmware file: firmware/medicine_dispenser.ino

#include <Wire.h>
#include <RTClib.h>
#include <WiFi.h>
#include <Servo.h>

// ===== Lecture 1: Smart medicine dispenser overview =====
// The ESP32 is the brain. It reads time, checks the schedule,
// decides if a dose should be given, and controls the motor.
const char* wifiName = "SchoolWiFi";
const char* wifiPassword = "ReplaceWithPassword";

// ===== Lecture 2: RTC and IR sensor =====
RTC_DS3231 rtc;
const int irSensorPin = 34;       // IR sensor input pin
const int buzzerPin = 25;         // buzzer output pin
const int statusLedPin = 26;      // green or red LED pin

// ===== Lecture 3: Servo / carousel motor =====
Servo medicineServo;
const int servoPin = 18;
const int carouselSteps = 5;

// ===== Lecture 4: Safe wiring and power =====
// Ground all devices together. Connect 3.3V or 5V carefully as shown in the wiring guide.
// Never connect a sensor or motor incorrectly to a digital pin without checking its voltage level.

// ===== Lecture 5: Schedule logic =====
struct DoseSchedule {
  int hour;
  int minute;
  bool enabled;
};

DoseSchedule doses[] = {
  {8, 0, true},
  {12, 30, true},
  {18, 0, true}
};

const int totalDoses = 3;
bool missedDose = false;

// ===== Lecture 6: Wi-Fi and caregiver alerts =====
void connectToWiFi() {
  Serial.print("Connecting to Wi-Fi...");
  WiFi.begin(wifiName, wifiPassword);

  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }

  Serial.println();
  Serial.println("Wi-Fi connected.");
}

void readRtcTime() {
  DateTime now = rtc.now();
  Serial.print("Current time: ");
  Serial.print(now.hour());
  Serial.print(":" );
  Serial.print(now.minute());
  Serial.print(":" );
  Serial.println(now.second());
}

bool checkTabletIsDispensed() {
  // If the IR sensor sees a gap or a signal change, a tablet passed.
  int sensorValue = digitalRead(irSensorPin);
  return sensorValue == LOW;
}

void rotateCarousel() {
  Serial.println("Rotating medicine carousel...");
  medicineServo.attach(servoPin);
  medicineServo.write(90);
  delay(500);
  medicineServo.write(0);
  delay(250);
  medicineServo.detach();
}

void dispenseMedicine(int doseIndex) {
  Serial.println("Medicine dose started.");
  rotateCarousel();

  if (checkTabletIsDispensed()) {
    Serial.println("Tablet released successfully.");
    digitalWrite(statusLedPin, HIGH);
    tone(buzzerPin, 1000, 250);
  } else {
    Serial.println("No tablet detected. Missed dose alert.");
    missedDose = true;
    digitalWrite(statusLedPin, LOW);
    tone(buzzerPin, 200, 800);
  }
}

void checkSchedule() {
  DateTime now = rtc.now();

  for (int i = 0; i < totalDoses; i++) {
    if (doses[i].enabled && now.hour() == doses[i].hour && now.minute() == doses[i].minute) {
      Serial.println("Medicine schedule matched.");
      dispenseMedicine(i);
      return;
    }
  }
}

void sendCaregiverAlert(String message) {
  Serial.println("Caregiver alert: " + message);
  // In a full project, this could send data to a dashboard or cloud service.
}

void setup() {
  Serial.begin(115200);
  pinMode(irSensorPin, INPUT);
  pinMode(buzzerPin, OUTPUT);
  pinMode(statusLedPin, OUTPUT);

  // Connect to Wi-Fi later in the project.
  connectToWiFi();

  if (!rtc.begin()) {
    Serial.println("RTC not found. Check wiring.");
    while (1) delay(10);
  }

  if (rtc.lostPower()) {
    Serial.println("RTC lost power. Set the time.");
    rtc.adjust(DateTime(F(__DATE__), F(__TIME__)));
  }
}

void loop() {
  readRtcTime();
  checkSchedule();

  if (missedDose) {
    sendCaregiverAlert("A dose was missed or not detected.");
    missedDose = false;
  }

  delay(60000);  // check once every minute
}
Starter version: this code uses the key lines for time checking, schedule matching, motor rotation, and missed-dose detection.
Extension challenge: add a multi-dose schedule, store medicine history on the device, and send a daily summary to a caregiver dashboard.

Wiring and safety checklist

  • Connect all grounds (GND) together before testing the system.
  • Use the correct voltage: ESP32 usually runs on 3.3V logic; motors and some modules may need 5V or a driver board.
  • Keep a clear gap between power lines and sensor wires to avoid noise.
  • Place the IR sensor in a safe position so it can see the tablet path without being blocked.
  • Use a buzzer and LEDs only with a current-limiting resistor or a safe driver circuit.
  • Check battery polarity carefully before powering the system.
  • Do not touch the motor or moving carousel while it is spinning.

Short test plan for each lecture

Lecture 1

Label each part of the system and explain what it does. Use the Input → Process → Output model.

Lecture 2

Open the Serial Monitor and verify the RTC prints the correct time. Test the IR sensor with a hand or a small object.

Lecture 3

Rotate the carousel one step at a time. Check that the medicine tray moves to the correct compartment.

Lecture 4

Power the system safely and check each wire. Verify the buzzer, LEDs, and display work without overheating.

Lecture 5

Set a known time in the code and verify the dispenser triggers at the matching time.

Lecture 6

Test the missed-dose warning and check any Wi-Fi transmission or caregiver alert message.
